# Данные, анализ и демонстрация

Инструкция для запуска скриптов из **корня репозитория**. Сначала установите пакеты:

```bash
python -m pip install -r requirements.txt
```

## Подготовка и анализ синтетических данных

1. `python src/1_generate_data.py` — создаёт `data/run_log.csv` и `data/test_scenarios.json`. Генератор использует фиксированное зерно случайности `42`; исходные данные искусственные.
2. `python src/2_analysis.py` — читает журнал, создаёт `output/graph1_conflict_pairs.png`, `graph2_hot_sources.png`, `graph3_peak_hours.png`, `graph4_run_types.png` и `output/summary.md`.
3. `output/ai_analysis.md` — готовое текстовое осмысление результатов средствами ИИ: выявленные узкие места, их подтверждение числами и предложения по требованиям. Исходные показатели рассчитаны Python-скриптом, не ИИ.

**Внимание:** запуск генерации и анализа перезаписывает соответствующие существующие файлы. При проверке уже подготовленных результатов повторно генерировать данные необязательно.

## Запуск оркестратора

```bash
python -m unittest discover -s tests -v
python -m src.run_scenarios
```

В `run_scenarios.py` выберите номер от 1 до 5; консоль покажет статусы, число конфликтов и итоговое модельное время, затем откроется диаграмма выполнения. Сценарии иллюстрируют разные даты одного процесса, независимые процессы, дубли, предотвращение deadlock и ночной пик.

Скрипт проверяет отсутствие оставшихся задач, соответствие числа обработанных заявок и отсутствие пересечений общих ресурсов; текстовое поле `expected` из JSON выводится для сравнения человеком, а не превращается автоматически в отдельные проверки каждого ожидаемого события.

## Необязательный ML-эксперимент

`src/3_model.py` — самостоятельная демонстрация `GradientBoostingRegressor`. **В MVP модель не подключена к оркестратору.** Чтобы запустить только этот эксперимент, дополнительно установите:

```bash
python -m pip install scikit-learn
python src/3_model.py
```

Результат: `output/model_results.txt` и `output/graph5_model.png`. Эксперимент проводится на синтетических данных; его точность нельзя переносить на реальные банковские процессы.
