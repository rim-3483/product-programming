# Моя часть: данные, анализ, ИИ

## Как запускать (нужен Python и `pip install pandas scikit-learn matplotlib`)
```
python 1_generate_data.py     # журнал запусков и сценарии для теста -> папка data
python 2_analysis.py          # графики 1-4 и summary.md -> папка output
python 3_model.py             # модель прогноза времени, график 5 -> папка output
```
Запускать по порядку, каждый файл можно открыть и прочитать сверху вниз: везде комментарии.

## Шаг 3 (ИИ-анализ): делаем вручную в любом ИИ-чате
1. Откройте `output/summary.md`, скопируйте текст.
2. Вставьте в чат вместе с промптом:

> Ты аналитик бизнес-процессов в банке. Ниже сводка журнала запусков системы оценки рисков, где нет единого диспетчера: процессы запускаются вручную и по расписанию независимо.
> [вставить summary.md]
> 1) Назови 3-5 главных узких мест и объясни причину каждого (опирайся только на цифры из сводки). 2) Для каждого предложи изменение в расписании или правилах запуска. 3) Сформулируй 5 системных требований к модулю-оркестратору. Отвечай по-русски, по пунктам, коротко.

3. Сохраните промпт и ответ в файл `ai_analysis.md` (жюри нужно показать, что ИИ-анализ был) и допишите, что из ответа подтверждается вашими цифрами.
